# راهنمای نمایندگی‌ها

متن راهنما یک جا نوشته شده: `frontend/src/content/guide.js`. همان فایل هم صفحه‌ی «راهنما» داخل پنل را می‌سازد و هم این PDF را. عکس‌ها در `frontend/assets/guide/`.

بازسازی PDF بعد از هر تغییر:

```bash
node docs/guide/render.mjs
```

عکس تازه بعد از تغییر رابط کاربری (دو سرور محلی بالا باشند و داده‌ی نمونه سید شده باشد):

```bash
node docs/guide/screenshots.mjs
```

هر عددی که در راهنما آمده (سقف‌ها، عمر آگهی، تعداد اخطار) از کد خوانده شده است. اگر قانونی تغییر کرد، راهنما هم باید تغییر کند.
