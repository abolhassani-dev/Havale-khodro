# راهنمای نمایندگی‌ها

`راهنمای-فرانوکار.pdf` از `index.html` ساخته می‌شود. متن راهنما همان فایل HTML است؛ عکس‌ها در `img/`.

بازسازی بعد از تغییر رابط کاربری:

```bash
# ۱) سرورهای محلی بالا باشند (API روی 3000، فرانت روی 5173) و داده‌ی نمونه سید شده باشد
# ۲) اسکرین‌شات‌ها (نوشته‌شده برای همین دو سرور محلی؛ مسیر خروجی را در فایل تنظیم کنید)
node docs/guide/screenshots.mjs
# ۳) رندر PDF
node docs/guide/render.mjs
```

هر عددی که در راهنما آمده (سقف‌ها، عمر آگهی، تعداد اخطار) از کد خوانده شده است. اگر قانونی تغییر کرد، راهنما هم باید تغییر کند.
