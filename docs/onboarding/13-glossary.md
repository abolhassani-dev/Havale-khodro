# فصل ۱۳ — واژه‌نامه

**در این فصل:** واژه‌های محصول و کد، کنار هم — چون در کد به انگلیسی و در رابط به
فارسی‌اند و باید یکی را به دیگری ترجمه کنید.

| فارسی (رابط) | در کد | یعنی |
|---|---|---|
| نمایندگی | `AGENT`, agency | حساب یک نمایندگی خودرو؛ کاربر اصلی محصول |
| زیرنمایندگی / شعبه | sub-agent, `parentId` | حسابی زیر یک نمایندگی مادر، با اشتراک مادر |
| نمایندگی مرکزی / مادر | parent, reseller | نمایندگی‌ای که ظرفیت می‌خرد و شعبه می‌سازد |
| ظرفیت | seat, `seatCredits`, `SeatOrder` | حق ساختن یک زیرنمایندگی برای یک دوره؛ پیش‌خرید با فیش |
| کد نمایندگی | `agencyCode` | شناسه‌ی خوانای نمایندگی (مثلاً `T-1234`)؛ شعبه‌ها پسوند می‌گیرند |
| مسئول هماهنگی | `coordinatorName/Phone` | کسی که خریدار به او زنگ می‌زند — این شماره پنهان است |
| حواله | `HAVALE`, `Listing.market` | حق تحویل خودرویی که به کارخانه پرداخت شده |
| ثبت‌نامی | `REGISTRATION` | ظرفیت ثبت‌نام در طرح فروش کارخانه |
| خودرو (آماده) | `CAR` | خودروی فیزیکی، صفر یا کارکرده |
| قطعات | `PARTS` (ساخته نشده) | بازار چهارم، «به‌زودی» |
| آگهی | listing | یک ردیف `Listing` در هر بازار |
| آگهی فروش / درخواست خرید | `kind: OFFER / REQUEST` | فروشنده می‌گذارد / خریدار می‌خواهد |
| صلح / وکالتی | `solh: SOLH / VEKALATI` | نوع واگذاری حواله |
| مبلغ حواله / واریزی / قیمت خودرو | `amountToman`, `paidAmountToman`, `carPriceToman` | سه عدد جدا؛ `moneyInput` |
| مدت تحویل / مدت واریز | `deliveryDays`, `depositDays` | روز؛ عمر آگهی = مدت واریز |
| نمایش مشخصات | reveal, `ContactReveal` | خرج یک واحد سهمیه برای دیدن تماس + متن آزاد + عکس |
| سهمیه‌ی روزانه / ماهانه | `dailyLimit`, `monthlyLimit`, `resolveAccess()` | از پلن یا override حساب؛ مشترک بین بازارها |
| اشتراک | `Subscription`, `Plan` | دوره‌ی ۳۰ روزه؛ `origin: ADMIN` یا `PARENT_SEAT` |
| منقضی / ابطال / تعلیق | `EXPIRED` / `CANCELLED` / `SUSPENDED` | سه چیز مختلف: زمان تمام شد / مدیر دوره را بست / حساب بسته شد |
| گزارش تخلف | `ViolationReport` | ادعای نماینده درباره‌ی آگهی؛ `reason` از فهرست بسته |
| اخطار | strike, `fakeStrikes`, `falseReportStrikes` | تأیید تخلف = یک اخطار؛ گزارش مغرضانه = اخطار برای گزارش‌دهنده |
| سه اخطار | `STRIKE_THRESHOLD = 3` | تعلیق خودکار |
| اطلاعیه | notice | صندوق تصمیم‌های سامانه درباره‌ی این حساب (بدون جدول) |
| تیکت | `Ticket` | پشتیبانی؛ دسته‌ها: اشتراک، ظرفیت، آگهی، اعتراض، فنی، سایر |
| کارتابل | pending queue (admin dashboard) | صف‌های معطل مدیر با سن قدیمی‌ترین کار |
| میز | desk, `MARKETS` (admin) | جدول مدیریت آگهی‌های یک بازار |
| کاتالوگ | `CarCompany/Brand/Model/Color` | فهرست بسته‌ی خودروها |
| نوع بدنه | `bodyType` | سدان/هاچبک/شاسی‌بلند/وانت دوکابین/تک‌کابین — از کاتالوگ، نه فروشنده |
| وضعیت بدنه | `bodyStatus` (Json)، `bodyGrade` | جدول ۲۲ قطعه؛ خلاصه‌ی یک‌کلمه‌ای مشتق (بدون رنگ … شاسی‌خورده) |
| نقشه‌ی بدنه | `ui/bodyMap.js` | نمایش سه‌نمایی با نقطه‌های رنگی |
| قیمت روز | car prices, `CarPriceItem/Run/History/Watch` | فهرست بازار از منبع بیرونی؛ **نام منبع در رابط نمی‌آید** |
| فهرست من | watch, star | ستاره‌های هر حساب در قیمت روز |
| با تأخیر | stale | آخرین اجرای موفق قدیمی‌تر از ۳ ساعت |
| راهنما | guide, `guideSeenAt`, `content/guide.js` | راهنمای داخل پنل؛ یک بار تأیید اجباری |
| راهنمای این بخش | `PAGE_CHAPTER` | لینک نوار بالا به فصل مربوط |
| مدیر کل / پشتیبانی / مالی | `SUPER_ADMIN / SUPPORT / FINANCE` | نقش‌های مدیریتی |
| مالک | `OWNER` | نامرئی؛ بدون لاگ؛ نامش هیچ‌جا |
| لاگ کارها / فنی / امنیتی | `ActivityLog / ErrorLog / SecurityEvent` | سه لاگ با سه مخاطب |
| بستن آدرس | `BlockedIp` | دستی، از پنل مالک |
| نگه‌داری | retention, `nightly.js` | آرشیو و پاک‌سازی شبانه |
| فرش کردن | fresh reset | دیتابیس از صفر پیش از نمایندگی واقعی |
| دیده‌بان | watchdog | کرون ۵ دقیقه‌ای سلامت و ترمیم |
| preflight | `deploy/preflight.sh` | «سرور همان است که باید؟» |
| اسموک | `tests/smoke.mjs` | تست مرورگری end-to-end |
| dto | `*.dto.js` | سریالایزر؛ مرز پنهان‌سازی |
| رجیستری بازار | `marketRegistry.js` | هر بازار خودش را به هسته معرفی می‌کند |
| هسته | kernel: `listing/`, `subscription/`, `report/`, `notice/` | آنچه بین بازارها مشترک است |
