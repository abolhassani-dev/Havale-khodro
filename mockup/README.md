# موک‌آپ سامانه حواله خودرو — فاز ۱

فایل `index.html` را در مرورگر باز کنید. دیتابیسی در کار نیست؛ داده‌ها نمونه‌اند.

## نوار پایین صفحه

- **صفحه:** پرش مستقیم به هر کدام از ۲۲ صفحه
- **اشتراک:** فعال / منقضی — قواعد مخفی‌سازی بند ۷ سند زنده اعمال می‌شوند
- **نقش:** مدیر کل / پشتیبانی / مالی — جدول دسترسی بند ۱۱.۱۲

## چیزهایی که واقعاً کار می‌کنند

- جستجو و فیلترها روی داده‌ی نمونه
- دکمه‌ی «نمایش مشخصات»: سقف روزانه را مصرف می‌کند و پیام ثبت‌شدن می‌دهد
- درخواست خرید بدون رنگ، در همه‌ی فیلترهای رنگ دیده می‌شود
- در حالت اشتراک منقضی: مشخصات کاملاً مخفی، دکمه‌های ثبت و تمدید غیرفعال
- نقش پشتیبانی و مالی: صفحه‌های خارج از دسترس، پیام «دسترسی ندارید»
- در مانیتورینگ، کلیک روی هر ردیف تایم‌لاین → پرونده‌ی کامل آن رویداد
- کلیک روی هر ردیف «چه کسی چند مشخصات دیده» → فهرست دقیق آگهی‌های بازشده
