# archive/ — چیزهایی که نگه داشته‌ایم ولی زنده نیستند

هیچ‌چیز در این پوشه اجرا، سرو یا import نمی‌شود. این‌جا برای «شاید روزی لازم شد»
است، نه برای کار روزمره. اگر چیزی از این‌جا لازم شد، بیرونش بیاورید و در
`docs/handover.md` بنویسید چرا.
